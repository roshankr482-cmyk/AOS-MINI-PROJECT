Meet the six strategies

SCAN and C-SCAN run all the way to the disk edge. LOOK and C-LOOK turn back at the last real request. Return jumps count toward the distance, and duplicate requests cost nothing. The maths is done by the C engine (backend/algorithms.c); this page only draws the result.

FCFS FAIR

Serves requests in arrival order. Simple and fair, but the head can zig-zag wildly.

SSTF GREEDY

Always hops to the nearest waiting request. Short trips, but far-away requests can starve.

SCAN ELEVATOR

Sweeps to one edge, then reverses and sweeps back, like a lift serving floors.

C-SCAN CIRCULAR

Sweeps one way only. At the edge it flies back to the start and sweeps again for even waits.

LOOK SMART SCAN

SCAN that does not waste a trip: it reverses at the last request instead of the disk edge.

C-LOOK SMART C-SCAN

C-SCAN that jumps back from the last request, skipping the empty stretch of disk.
